### 决策 2: 批准 RuleSet 作为唯一真相源策略 ✅

**决策内容**:
批准将 **RuleSet** 确立为架构治理的**唯一真相源**（Single Source of Truth），其他系统（ADR、测试、Agent 指令）自动派生/生成。

**实施策略**:
```
            ┌─────────────────┐
            │   RuleSet       │
            │ (唯一真相源)    │  ◄─── 所有规则定义在此
            └────────┬────────┘
                     │
 ┌───────────────────┼───────────────────┬──────────┐
 ▼                   ▼                   ▼          ▼
┌─────────┐    ┌──────────┐        ┌─────────┐  ┌──────┐
│   ADR   │    │   测试    │        │  Agent  │  │  CI  │
│  文档   │    │  生成     │        │  指令   │  │ 验证 │
└─────────┘    └──────────┘        └─────────┘  └──────┘
(自动派生)      (自动生成)          (基于 API)    (自动)
```

**理由**:
1. 消除不一致：自动同步，无手工维护
2. 提升准确性：Agent 使用结构化 API
3. 扩大覆盖：从 5 个测试扩展到 500+
4. 提高效率：年化节省 312 小时，ROI 350%

**投票结果**: 一致通过
