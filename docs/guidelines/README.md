## 📖 文档说明

### 权威性声明

本目录下的所有文档均为**指导性文档**，提供最佳实践建议，**不具备架构裁决权**。

- ✅ **用途**：提供编码规范、最佳实践、常见问题解答
- ✅ **定位**：辅助性参考材料，帮助开发者理解和实施架构决策
- ❌ **非用途**：定义架构约束、做出架构决策

### 权威依据

如有冲突或疑问，请始终以以下文档为准：

1. **ADR 文档** (`docs/adr/`) - 架构决策记录，具有最高权威
2. **架构宪法层** - ADR-001 至 ADR-005，定义核心架构原则
3. **治理体系文档** - ADR-900 系列，定义治理规则和流程

### 使用建议

1. **新功能开发前**：查阅相关指南，了解最佳实践和规范要求
2. **代码审查时**：参考指南检查代码质量和一致性
3. **遇到问题时**：查看常见问题（FAQ）部分寻找解决方案
4. **规范演进**：通过 Issue/PR 提出改进建议，持续完善指南
